## The Infected Grounds: Zombies Siege · V0.81

### Jouer
- En ligne : https://ghoster-001.github.io/Zombie-Survivor-By-C02/
- Hors ligne : télécharger **Zombie-Survivor-By-C02-0.81.zip**, l'extraire, ouvrir `index.html` (le dossier `js/` doit rester à côté).

### Nouveautés
- **Réalité virtuelle (WebXR)** dans le mode 3D : bouton « ENTRER EN VR » quand un casque est détecté (Meta Quest, Pico, casques PC via un navigateur compatible).
  - Stick gauche : marcher (vers où l'on regarde) · stick droit : tourner par crans de 30°
  - Gâchette droite : tirer, en visant avec la main · A : sauter · B : ramasser · poignée droite : changer d'arme · X/Y : bonus
  - Panneau au poignet gauche : vie, arme, munitions, vague / zone
  - Fonctionne en solo, en coop et en Battle Royale (le réseau est le même qu'à l'écran)
- **8 nouvelles tenues gratuites** : médecin, pompier, policier, agent, bûcheron, pilote, punk, camouflage neige.

### Rappel V0.75 → V0.80
Remaster graphique (crépuscule, ombres, reflets, bloom), grands immeubles enterables meublés, matériaux en relief, vrais modèles 3D (CC0), collisions revues, code en modules.

### Version PC (en développement)
Le dossier `rust/` contient la version native (Rust + Bevy) prévue pour Steam : rendu physique (atmosphère, ombres, SSAO, reflets, brume volumétrique), ville enterable, ennemis animés, 8 armes, vagues. Elle n'est pas encore jouable de bout en bout et n'est pas incluse dans ce zip.
